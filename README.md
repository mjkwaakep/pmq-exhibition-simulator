# PMQ 포스터 월 시뮬레이터

실제 도면(`01_Qube_원본도면.pdf`, `02_포스터월_위치표시.pdf`)과 현장사진을 기준으로 만든
LAYOUT / 3D PERSPECTIVE 2-in-1 웹 시뮬레이터입니다.

## 실행 방법 (중요)

`index.html`을 더블클릭해서 열면 **안 됩니다.** `posters.json`을 `fetch()`로 불러오는데,
`file://`로 열면 브라우저가 로컬 파일 fetch를 막아 포스터 목록이 비어 보입니다.
반드시 정적 서버로 열어야 합니다.

```bash
cd "pmq-poster-wall 2"
python3 tools/serve.py
# 이후 http://localhost:5300 접속
```

(Claude Code 세션에서는 `.claude/launch.json`에 등록된 `pmq-poster-wall` 프리뷰로 이미 확인함.
서버 실행 스크립트는 `tools/serve.py`에도 사본이 있음.)

## 구조

```

css/style.css        스타일

js/pack.js            포스터 자동 배치(매서너리/스카이라인 패킹) 엔진 — mm 단위 실측 계산
js/view-layout.js     LAYOUT VIEW (입면도, SVG)
js/view-3d.js          3D PERSPECTIVE VIEW (three.js, 실제 geometry, 갤러리풍 조명/바닥)
js/app.js              상태 관리 + UI 이벤트 바인딩 (두 View가 레이아웃 데이터 1개를 공유)
posters.json           포스터 메타데이터(제목/연도/카테고리/파일명/원본비율) — 253장
posters/               포스터 대표 이미지(가로 640px, everyday-practice.com에서 자동 수집)
vendor/                three.js (로컬 벤더링, CDN 의존 없음)
tools/build_posters.py 포스터 이미지 재수집 스크립트
tools/serve.py          로컬 정적 서버 스크립트
```

## 포스터 데이터는 어디서 왔나

`PMQ Exhibition Work List EP_Selected.numbers`의 URL 열(everyday-practice.com 작업 페이지 링크)을
스튜디오 사이트의 WordPress REST API와 매칭해서 대표 이미지를 자동으로 내려받았습니다.
365개 작업 중 세로형(A0/A1/A2 비율 0.62~0.80에 가까운) 이미지 253개를 추려 `posters.json`에 담았습니다.
(원 스펙에서 언급한 "Google Sheets"는 아직 만들어지지 않아, 동일한 정보가 이미 담긴 이 리스트를 사용했습니다.
 나중에 실제 Google Sheets를 쓰려면 `tools/build_posters.py`를 그 시트 export로 바꿔 실행하면 됩니다.)

재수집하려면:
```bash
pip install numbers-parser Pillow
python3 tools/build_posters.py "PMQ Exhibition Work List EP_Selected.numbers" .
```

## 실사 렌더 (3D PERSPECTIVE의 "렌더 · 실사 이미지")

평소 3D 미리보기는 가볍게 두고, 버튼을 누르면 지금 카메라 그대로 경로 추적(path tracing)으로
빛 · 그림자 · 반사를 계산해 점점 선명해지는 이미지를 만든다(`js/render-pt.js`,
`vendor/three-gpu-pathtracer.module.js` 0.0.23 + `vendor/three-mesh-bvh.module.js` 0.7.8).
600샘플이 쌓이면 멈추고, "이미지 저장"으로 PNG를 내려받는다. 렌더하는 동안에만:

- Aberdeen Street 쪽 큰 창 너머에 빛을 내는 풍경 면을 세우고, 창으로 비스듬히 햇빛이 들어온다.
- 포스터 벽마다 천장 트랙 스팟(2.2m 간격)을 달고, 천장 라인조명 · 비상구 표시등이 실제로 빛을 낸다.
- 포스터는 `walls/hires/wall0N.jpg`(피그마에서 1px = 1mm로 내보낸 시안)를 2.5m 안팎 조각으로 나눠 붙인다.
  벽 시안을 바꿀 때는 `walls/wall0N.png`와 함께 이 파일도 같이 바꿔야 렌더에 반영된다.
- 치수선 · 동선 화살표 · 비상구 구역 · 사람 실루엣은 숨긴다.

## 물리 규칙 (절대 변경 금지 — `js/constants.js`에 고정)

- ㄱ자(L자) 구조 — 코너가 하나뿐: Wall01(화이트월, 15,000×2,500mm, 불투명)에서 90도
  꺾여 Wall02(반투명, 7,000×2,200mm) → 통로 1,000mm → Wall03(반투명, 8,000×2,200mm)이 같은 직선
  위에서 이어진다. Wall02·Wall03을 하나로 합쳐 표시하지 않고, 사람이 지나가는 1m
  통로를 사이에 둔 별개의 두 벽으로 렌더링한다. 전체 구간(통로 포함) 31m.
- 벽면 그래픽은 인디자인 시안을 내보낸 입면 이미지(`walls/wall01~03.png`)를 그대로 쓴다.
  `js/constants.js`의 각 벽 `image`를 지우면 예전 자동 배치(패킹) 방식으로 돌아간다.
  이미지를 교체할 때는 같은 파일명으로 덮어쓰면 되고, 벽 배경(회색)은 `js/wall-image.js`가
  자동으로 투명 처리한다.
- A0 841×1189 / A1 594×841 / A2 420×594mm, 포스터 간격 50mm(고정), 실제 비율 유지(찌그러뜨리지 않음)
- 세 벽은 서로 독립적으로 배치된다(한 벽이 넘치면 다른 벽으로 넘기지 않음) — 벽마다 A0/A1/A2
  수량을 따로 조절.
- 배치는 고정된 줄(row)도 아니고, 순수 기하학적 bin packing(MaxRects: 언제나 "가장
  낭비 없는 단 하나의 자리")도 아니다. 그렇게 하면 밀도는 높아도 결과가 격자처럼
  규칙적으로 보인다(빈 사각형의 모서리가 항상 이전 사각형에 맞춰 정렬되기 때문).
  그래서 `pack.js`의 `packWallFreeform`은 빈 사각형(free rect) 추적은 밀도를 지켜주는
  장치로 그대로 쓰되, 자리를 고르는 방식을 바꿨다:
  1. A0/A1/A2를 하나의 리스트로 합쳐 순서를 완전히 무작위로 섞는다.
  2. 포스터마다, 지금 들어갈 수 있는 여러 빈 사각형(무작위로 최대 28개 살펴봄) 각각에서
     후보 위치를 뽑는다 — 사각형의 모서리(가장 낭비 없는 자리) 하나와, 거기서 조금씩
     랜덤하게 벗어난 지점 여러 개(최대 90mm, 그만큼 50mm보다 더 넉넉한 여백이 생김)를
     함께 만든다.
  3. 모든 후보를 "주변에 다른 크기가 많을수록 +, 같은 크기가 많을수록 −", "위/아래/
     왼쪽 경계선이 이미 있는 포스터와 나란히 맞춰지면 −", "너무 헐렁하면 소폭 감점"으로
     채점하고, **유일한 최고점이 아니라 상위 후보(top-K) 중 하나를 무작위로** 고른다.
  4. 이렇게 만든 전체 레이아웃 후보를 여러 개(`PACK_ATTEMPTS`개) 생성해서 "점유율 −
     같은 사이즈 인접 비율"로 점수를 매겨 가장 좋은 것을 채택한다(`scoreLayout`).
  간격은 포스터마다 GAP_MM/2씩 패딩을 둔 발자국으로 계산해서 50mm 미만은 절대 나오지
  않지만, 후보 자체가 매번 다른 모서리·다른 여백에서 나오므로 50mm보다 더 벌어진
  자리도 자연스럽게 생긴다.
- 실측(Wall01, 기본 채움): 점유율 약 65%(격자형 MaxRects의 ~90%보다는 낮지만, 이 값은
  "빈 공간을 무조건 최소화하지 않는다"는 요구를 반영한 의도된 트레이드오프다) · 맞닿은
  포스터 쌍 중 같은 사이즈 비율이 이 크기 비율(A0:A1:A2≈5:15:35)에서 순수 무작위로도
  나오는 통계적 하한(~49%)보다도 낮은 ~40%로, 오히려 무작위보다 더 잘 섞여 있다.
- "이 벽 꽉 채우기" 버튼과 기본값은 위 패킹을 실제로 반복 시도해서 그 벽이 넘치지 않는
  최대 수량을 찾아낸다(추정이 아니라 실측 기반) — 그래서 기본 상태에서도 3면이 빈 곳 없이
  채워짐. 요청 수량이 그 벽의 용량을 넘으면 "배치 못함" 경고만 띄우고 절대 겹치거나 벽
  밖으로 나가지 않음.
- 3D 뷰는 목업 사진 합성을 대체하며, 실제 현장사진을 참고해 사진에 가깝게 다듬었다:
  - **층고 5,000mm** 기준(실측 없어 가정값), 포스터 월 2,500mm는 그 절반 비율을 정확히 유지.
  - 바닥은 결이 있는 회색 카펫 텍스처(캔버스로 생성), 천장은 짙은 다크그레이 + 길쭉한
    사각 라인조명 3열(현장사진의 조명 배치를 참고). 조명 3열은 "3D 옵션 → 천장 조명(형광등)
    표시" 체크박스로 켜고 끌 수 있다(`setCeilingLightsVisible`).
  - 전체 밝기는 레퍼런스 스튜디오 사진처럼 부드럽고 밝은 확산광 위주(hemisphere/ambient를
    크게 높이고 톤매핑 노출 1.35)로 맞췄고, 배경색·포그도 밝은 톤으로 바꿔 어두운 보이드
    느낌을 없앴다.
  - **반투명월(Wall02/03)의 금속 프레임은 포스터가 붙는 전면이 아니라 반드시 후면에
    둔다**(`setWalls`의 `frameSign = -posterSign`) — 정면에서 보면 포스터 위로 프레임이
    지나가지 않고, 포스터가 없는 반투명 영역에서만 후면 프레임이 은은히 비친다. 프레임은
    얇은 브러시드 스테인리스(metalness 0.72 / roughness 0.48, 크롬처럼 반짝이지 않음)로,
    두께도 기존의 절반 이하로 줄임.
  - 공간은 **가로 30m × 깊이 20m × 층고 5m의 사방이 완전히 막힌 방**이다(`_buildEnclosure`,
    `constants.js`의 `ROOM_WIDTH_MM`/`ROOM_DEPTH_MM`). 원본 도면(색상 표시본) 비례를 따라:
    코너(Wall01↔Wall02)는 왼쪽 외벽에서 10m, 상단 외벽에서 2m 떨어진 지점에 있고,
    Wall01(15m)이 거기서 오른쪽으로 뻗어 전면 창까지 5m를 남기고, Wall02(7m)+통로(1m)+
    Wall03(7m)이 거기서 아래로 뻗어 하단 외벽까지 3m를 남긴다. 즉 왼쪽·상단·하단은
    흰색 외벽(합계 400㎡), 오른쪽은 전면 창(20m×5m=100㎡)으로 방이 닫혀 있다. 각 포스터
    월과 그 뒤 외벽 사이에 실제 여백(2~10m)이 있어서, 예전 버전처럼 포스터 월 바로
    뒤에 별도의 "백업 벽"을 덧세우지 않아도 카메라가 어느 방향으로 돌아가도 뚫린 곳이
    없다.
  - 렌더러 그림자(PCFSoftShadowMap) 활성화.
  - 전면 창은 바닥부터 천장까지 통유리인 커튼월이 아니라, 위(0.7m)·아래(1.0m)에
    흰색 벽 구조체를 두고 그 사이(3.3m)만 창으로 낸다. 프레임은 검은 세로선을 촘촘히
    반복하지 않고 얇은 실버/그레이 창호(멀리언 5개 + 상하 바)로만 마감했다
    (`_buildEnclosure`의 `mullionMat`). 창밖 풍경은 추상적으로 그린 텍스처가 아니라
    **실제 사진**을 쓰되(Wikimedia Commons, CC BY-SA 4.0, © Ibrahim Achiri, "A dense
    canopy of green trees"에서 잎이 우거진 부분을 크롭·보정한 `textures/outside.jpg`),
    포스터 월보다 시각적으로 튀지 않도록 낮은 오파시티(0.55)와 밝은 톤 필터를 얹어
    은은하고 흐릿하게 보이게 했다 — 2층에서 내려다보는 듯한 초록빛이 배경으로만
    비친다.
- 3D 뷰에는 허리 높이(900mm)의 가늘고 긴 테이블과 실제 사람 사진을 반투명 실루엣으로
  처리한 컷아웃 인물(건축 시각화용 "entourage")을 "3D 옵션" 체크박스로 켜고 끌 수 있다
  (`view-3d.js`의 `setTablesVisible`/`setPeopleVisible`). 인물 사진은
  [skalgubbar.se](https://skalgubbar.se)(건축 시각화용 무료 컷아웃 인물 아카이브,
  비상업/상업 모두 무료 — 이 프로젝트처럼 미건설 건축 시각화에 사람을 채우는 용도로만
  사용)에서 받아 `tools/process_people.py`로 데스처레이션 + 반투명(불투명도 ~62%) +
  가장자리 블러 처리했다(`people/person1~6.png`). 카메라가 움직여도 항상 카메라를
  정면으로 보도록 매 프레임 Y축으로만 회전하는 billboard(2D 컷아웃)로 세운다.
